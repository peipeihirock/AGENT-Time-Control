AGENT // TIME CONTROL — PWA 配布パッケージ

このパッケージは、既存の画面デザインを変更せずにホーム画面へ追加できるPWA構成です。

含まれるファイル
- index.html              アプリ本体（時計・ストップウォッチ・タイマー・カレンダー）
- manifest.webmanifest    アプリ名、アイコン、表示モードなどの設定
- sw.js                   オフラインキャッシュとPush通知受信処理
- icon-192.png / icon-512.png アプリアイコン（リポジトリ直下）

公開方法
1. このフォルダー内の全ファイルを、HTTPS対応のWebホスティングへアップロードします。
   例：GitHub Pages、Netlify、Cloudflare Pages など。
2. Android の Chrome で公開した HTTPS URL を開きます。
3. メニューから「アプリをインストール」または「ホーム画面に追加」を選びます。
4. インストール後、アプリを一度オンラインで起動してください。以後、キャッシュ済みの画面はオフラインでも開けます。

重要：タイマー／通知について
- 画面を開いている間のタイマーやアラームは、ページ内のJavaScriptで動作します。
- アプリを完全に閉じた状態でも指定時刻に確実に通知するには、スケジュールを保存してWeb Pushを送信するサーバー側の仕組みが別途必要です。
- sw.js はPush通知を受信して表示する処理を含みますが、通知を予定時刻に送信するサーバーは含まれていません。
- HTTPSと通知許可が必要です。

画面のHTML/CSS/JavaScriptおよび既存のデザインは変更していません。
